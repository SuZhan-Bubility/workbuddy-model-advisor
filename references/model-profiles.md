# 模型能力档案（供写"理由"时参考）

> 榜单名次几周就变，**本表侧重"能力特征"，不追精确排名**。计费以 `recommend.py --list` 实时读出的为准。

## 费率的两档价（示例）

同一模型在历史快照里出现过**两个不同费率**，说明服务端存在折扣机制。脚本会自动识别并展示：

| 型号 | 原价（高峰） | 折扣价（非高峰） | 省幅 |
|---|---|---|---|
| DeepSeek-V4-Pro | x0.51 | **x0.16** | 69% |
| DeepSeek-V4-Flash | x0.17 | **x0.06** | 65% |
| Hy3 | x0.05 | **x0.00**（免费档） | 100% |

> ⚠️ 以上数字仅用于说明机制，**随官方调整会变**，请以脚本运行时从本机读取的为准。
> **时段规则**：工作日 09:00–12:00 / 14:00–18:00 为高峰原价，其余时间为非高峰折扣。

## 思考强度机制（重要）

本机配置每个模型有 `reasoning.effort` 字段 = **默认强度**（high/medium/low）。
**配置里没有"各档对应多少费率"的表格** —— 强度通过"想得越久产生越多 token"间接影响成本。

脚本采用的**经验成本系数**（用于性价比折算，非精确值）：
`minimal 1.0 / low 1.1 / medium 1.25 / high 1.6`

### 强度由任务类型决定（设计如此）

| 任务类型 | 需求强度 | 理由 |
|---|---|---|
| crape / 批量爬取 | 低 | 逐条处理，开高只多烧积分 |
| research / 系统研究 | 高 | 长链条论证，强度决定结论质量 |
| code / 写代码调试 | 高 | 容错低，推理越深越少返工 |
| survey / ppt / video / writing / general | 中 | 结构整合类，中档最稳 |

### 卡片呈现口径（v1.0.7 起）

- **主显示：任务类型推荐的档位**（低 / 中 / 高），不同任务必然不同
- **对照：模型自身默认档位**；一致写"无需调整"，不一致给出升降建议并注明"不调也能跑"

> 为什么不再一律显示默认：本机 46 个模型默认全是 medium，只看默认值会让八类任务在卡面上完全一样。

> 若日后能确认某模型各档的精确倍率，写进 `recommend.py` 的 `EFFORT_COST_FACTOR` 即可。

## 两个角度的评分口径

- **做到最好**：成本维度按**原价**算 → 不计成本求最优，不被折扣干扰。
- **性价比最高**：成本维度按**折扣价**算 → 反映错峰后的真实划算度。

卡片每项标注「按原价评分 / 按折扣价评分」。设计取舍：**卡上不加"错峰建议"栏目**，只给费率和推荐。

## 八类任务的推荐逻辑

- **crape（爬取）**：成本权重高 → DeepSeek-V4-Pro（能力强且折扣后极便宜）双榜第一。
- **research（研究）**：能力权重 0.65 → best 是 GLM-5.2；value 因折扣转向 DeepSeek-V4-Pro。
- **survey（调研）**：能力 + 视觉权重 → best 是 GLM-5.2；读图环节建议切 GLM-5v-Turbo。
- **ppt（演示文稿）**：视觉 0.22 + 上下文 0.20 → best 偏 GLM-5.2，value 偏 Pro。
- **video（视频）**：视觉 0.24 + 工具调用 → 同样偏视觉强、能调工具的型号。
- **code（写代码）**：代码专精型号在 `ability_override` 里上浮（如 Kimi-K2.7-Code 0.94）。
- **writing（写作）**：能力 + 上下文 → best 偏 GLM-5.2。
- **general（兜底）**：均衡权重，未识别任务时使用。

> 具体名次会随本机模型清单和费率变化，**以脚本实时输出为准**，本表只描述权重逻辑。

## 诚实边界（写理由时必须体现）

1. **费率以快照为准，不以单次读数为准**——展示"原价/折扣价"两档 + 快照时间戳。
2. **折扣规则读不全**——本机无折扣/时段/免费额度字段，只能从快照反推"存在两档价"；**精确生效时间与限次免费次数给不出**，如实说明，不编。
3. Claude / GPT / Gemini 在本机**没有直接可选入口**。
4. 配置文件是应用层支持清单，用户套餐实际能勾选的**以界面为准**。
5. 推荐不代选 —— 最终切模型由用户在界面下拉框完成。
